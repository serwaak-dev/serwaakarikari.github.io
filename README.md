# Serwaa Karikari Faculty Website

A static, responsive multi-page academic website.

## Preview locally
Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
### GitHub Pages
1. Create a repository.
2. Upload all files in this folder.
3. Open Settings → Pages.
4. Deploy from the `main` branch root.

### Netlify
Drag the entire folder into Netlify Drop or connect the repository.

### University server
Upload the contents of this folder to the public web directory.

## Updating content
- Publications: `data/publications.json`
- Headshot: `assets/images/serwaa-karikari.jpg`
- CV: `assets/cv/Serwaa-Karikari-CV.pdf`
- Site styling: `css/style.css`
